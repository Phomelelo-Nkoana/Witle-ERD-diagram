# Witle-ERD-diagram
Witle Online Shop ERD diagram

Description overview

This project designs the entity relationship diagram for WitleShop (Pty) Ltd, a South African online retailer selling electronics, clothing and home appliances through a web and mobile platform.

The Problem

WitleShop (Pty) Ltd is growing fast and wants to build a new database system to manage customers, products, orders, payments, deliveries and suplliers, as a result they have hired me to design the database structure for them

The Dataset

The data used is from the WitleShop case study , which defines the business requirements and rules.
key dataset rules and requirements
Customers must register before ordering and can have multiple delivery addresses.
Each product belongs to one category and is supplied by one supplier.
An order belongs to one customer and can contain many products however a product can appear in many orders.
Each order has exactly one payment and one delivery.
Each delivery must go to one of the customer's registered addresses.
